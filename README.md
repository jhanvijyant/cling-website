# Cling Info Tech Website

Official landing page and web application for **Cling Info Tech** — *Making Your Ideas Happen*.

## 🚀 Overview
- **Modern Design**: High-converting, responsive layout with dark mode and interactive elements.
- **Interactive Project Builder**: Real-time project cost and timeline estimation tool.
- **Zero Build Dependencies**: Lightweight, fast-loading, pure HTML5, CSS3, and JavaScript.

## 📁 Files
- `index.html` — Primary entry point (ready for GitHub Pages or static web servers)
- `cling-home.html` — Original standalone page

## 🌐 Deploy to GitHub Pages
1. Go to your repository on GitHub: [cling-website](https://github.com/jhanvijyant/cling-website)
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your site will be published live in seconds!
